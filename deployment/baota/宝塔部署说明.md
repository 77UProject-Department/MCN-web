# 柒玖视界官网：宝塔面板部署说明

## 使用哪个压缩包

使用「柒玖视界官网-宝塔静态部署版」ZIP。这个包已经将生成好的网页放到压缩包根目录，解压后直接能看到 `index.html`、`app.js`、`content.js`、`styles.css`、`assets/` 和各栏目目录。

本包不包含项目外层文件夹或 `dist/` 外壳，不需要在服务器运行 npm、Node.js 或构建命令，也不需要数据库、PHP、PM2 或反向代理。

## 1. 创建静态站点

适用于宝塔 Linux 面板 + Nginx。进入「网站」→「添加站点」，填写自己的域名；如果当前面板需要选择 PHP 版本，选择「纯静态」。数据库、FTP 按需选择，不是本站运行的必要条件。不同面板版本的栏目名称可能略有区别。

使用宝塔创建的网站根目录，通常形如 `/www/wwwroot/你的域名/`。把自己的域名解析到服务器 IP，并确保网站所用 HTTP/HTTPS 端口可访问。

## 2. 上传并解压

进入这个站点的根目录，上传宝塔静态部署包，选择「解压到当前目录」。如果此目录已有旧网站，先在宝塔备份后再更新对应文件。

解压后的结构应为：

```text
/www/wwwroot/你的域名/
├── index.html
├── 404.html
├── app.js
├── content.js
├── styles.css
├── assets/
├── about/index.html
├── live/index.html
├── short-video/index.html
├── shop/index.html
├── news/index.html
├── news/content-value/index.html
└── 其他栏目目录/
```

网站目录/运行目录指向这一层，首页文档使用 `index.html`。不要把站点指向项目源码目录或多套一层目录；本站静态资源路径以 `/` 开头，需放在域名根目录使用。

## 3. 路由与 404 设置

本网站每个栏目都有真实的 `index.html`，Nginx 常规静态站点即可访问并刷新 `/about/`、`/live/`、`/news/content-value/` 等地址，不需要单页应用的「全部重写到首页」规则。

若需要明确设置路由和自定义 404，在网站「设置」→「配置文件」中找到当前站点的 `server { ... }`，在其中加入下面的块。如果已经存在 `location /`，修改已有块，不要再重复添加。保留宝塔管理的域名、根目录、证书与其他配置。

```nginx
location / {
    index index.html;
    try_files $uri $uri/ =404;
    error_page 404 /404.html;
}
```

以上内容是站点配置片段，不能替换完整的 Nginx 配置文件。保存时使用宝塔的配置检查；通过后重载 Nginx。附带的 `nginx-location.conf` 与此片段一致，只供复制配置，不需要上传到网站目录。

## 4. 确认网站可用

分别打开首页、`/about/`、`/live/`、`/news/content-value/`，并在内页刷新，确认图片和样式正常。访问一个不存在的地址应显示 404 页面，并返回 HTTP 404。

如仍显示宝塔默认欢迎页，检查站点根目录、首页文档顺序以及是否覆盖了默认的 `index.html`。如文字可见但图片或样式丢失，检查 `assets/`、`app.js`、`content.js`、`styles.css` 是否与 `index.html` 在同一层。

域名解析生效后，可在宝塔网站的 SSL 设置中配置证书，再启用 HTTPS。

## 后续修改

仅修改介绍、联系方式或已有条目的文字和图片路径，可以编辑网站根目录的 `content.js`；颜色和布局在 `styles.css`。使用宝塔在线编辑后，必要时强制刷新浏览器缓存。

增加或删除新闻文章、栏目时，建议在本地项目修改源码、执行 `npm run build`，再把最新 `dist/` 里的内容重新打包上传。删除文章时应同步移除服务器上对应的旧文章目录。本包是前端展示模板，没有表单收集、后台管理或数据库服务。

## 核验范围

交付前已执行本地构建、17 个页面的渲染与内部资源检查，并验证 ZIP 文件完整性。尚未登录你的宝塔面板，也未在你的服务器上保存配置或进行实际部署验证。
